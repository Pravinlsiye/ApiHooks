What you get

Six surfaces. One workflow. Everything stays in the browser unless you choose otherwise.

Node-edge canvas

HTML blocks, SVG connections, hand & pointer tools, Ctrl-wheel zoom, monochrome theme.

Browser executor

Run real HTTP workflows in-page. Variable interpolation, JSONPath outputs, success / fail branching.

Step debugger

Breakpoints on any block. Pause, resume, step. Inspect variables in a pinnable, detachable tree view.

ASP.NET embed

Drop app.UseSiyeFlowDesigner() into a .NET 10 API. The designer ships embedded, Swagger-UI style.

CLI runner

Save workflow JSON, run it headless from dotnet run -- execute --workflow path.

Typed schema

Single source of truth in workflow-models.ts. v2.0 node-edge graph, no legacy nesting.
